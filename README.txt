Kleenu Futter-Rechner – PWA

Dateien:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

Wichtig:
Eine PWA kann nicht zuverlässig direkt aus dem Download-Ordner per file:// installiert werden.
Sie muss über HTTPS (oder localhost) geöffnet werden.

Einfachste Veröffentlichung:
1. Diese Dateien auf GitHub in ein Repository laden.
2. GitHub Pages aktivieren.
3. Die erzeugte HTTPS-Adresse auf dem Android-Handy in Chrome öffnen.
4. "App installieren" oder "Zum Startbildschirm hinzufügen" wählen.

Die App funktioniert danach offline und speichert Einstellungen lokal auf dem Gerät.
